# Apple 메타데이터 재심사 점검

기준일: 2026-10-16. 대상은 Apple에서 2.3.10·2.3.7로 반려한 앱 1.0.0 (1001)의 한국어·영어(미국) 등록 문안이다. 아래 로컬 검수 결과는 App Store Connect 저장·이미지 업로드·재심사 접수 완료를 뜻하지 않는다. 과거 QA 기록, Google 자료와 공개 지원 사이트는 Apple 제품 페이지 문안과 구분한다.

현재 최신 제출 빌드는 **1001 / 심사를 통과하지 못함**이다. Apple 브라우저 연결이 되지 않고 기존 Developer 권한 API 키의 소개글 수정 요청이 403으로 차단되어 **Apple 등록값은 아직 수정 전이며 재심사도 미실행**이다. 권한을 임의로 확대하지 않았다. 아래 사이트 교정도 로컬 상태로 아직 공개하지 않았다. 새 앱 빌드의 성공이나 실제 iPhone 결제 검증 통과로 표시하지 않는다.

위 제목·부제·프로모션·키워드·Apple 전용 설명을 추출해 Android·Google·안드로이드, 이전 표시 브랜드, ADHD·치료·진단·1위·No.1·평생·100% 표현을 검사했다. 해당 Apple 공개 문안에는 없다. 제목·부제·키워드에는 가격·무료·할인 홍보, 경쟁 앱 이름도 없다. todo·to-do 계열 및 한국어 맞춤법 변형은 사용자 요청으로 유지한 일반 검색어다. 유사 검색어가 많아 검색 효율을 높이지 못할 수 있으나 이번 반려 사유로 확인된 것은 아니다.

기본 기능과 Pro 기능, 자체 7일 체험의 비자동결제, 연간 자동 갱신 구독, 현지 가격 확인, 구독 관리·해지·환불 안내를 설명에 유지했다. 설명의 무료 기능 안내는 이번 Apple 메시지가 허용한 설명 영역에 한정한다. 이미지에서 가격 홍보를 제거하면서도 추가 구독이 필요한 기능을 숨기지 않는다.

## 실제 기능과의 문안 대조

- `lib/services/feature_access.dart`: 첫 실행 7일 자체 체험과 Pro 이용 기간을 별도로 저장한다. 앱 체험이 StoreKit 구독을 자동 구매하는 동작은 없다.
- `lib/features/pro_screen.dart`: 무료로 유지되는 캘린더·할 일·메모·반복·완료·위젯 보기와 Pro의 알림·미루기·실행 보조·통계를 구분한다. 현지 가격·연간 기간·자동 갱신·구매 복원·관리 버튼이 있다.
- `lib/features/home_screen.dart`: 90일 완료 기록, 분류별 집계, 최근 30일 완료율·미룬 횟수·평균 미룬 시간·완료 시간대와 설명의 기능 범위가 일치한다.
- `lib/features/task_editor.dart`: 작은 첫걸음은 같은 회차를 하루 세 번 이상 미룬 뒤 5분 시작 안내에서 사용한다. 설명은 일반적인 작업 시작 보조로 표현하며 치료 효과를 주장하지 않는다.
- `lib/features/store_policy_links.dart`: 한국어·영어 지원·개인정보 링크를 언어별로 열며 iOS 이용약관은 Apple 표준 EULA를 사용한다.
- `pubspec.yaml`과 Dart 앱 소스 확인 범위에서 광고·분석 SDK 및 개발자 서버로 일정·메모를 전송하는 기능을 찾지 못했다. 문안은 일정·메모가 개발자 서버로 전송되지 않는다고 한정하며 모든 통신이 없다고 주장하지 않는다. 구매·구독 확인·공개 사이트·이메일 통신은 별개다. 이 확인은 네트워크 패킷 분석이나 모든 빌드 산출물의 보안 인증을 뜻하지 않는다.
- 앱 삭제·기기 변경 시 일정과 기록이 사라질 수 있음, 자체 클라우드 복구 없음, 구매 복원으로 일정이 돌아오지 않음, 알림·위젯의 OS 권한·집중 모드·절전·예약 범위 제한을 유지했다.

## 추가 발견과 마무리 확인

1. **앱 내부의 타 플랫폼 문구**: 점검 당시 Pro·개인정보 카드에 남은 `Apple 또는 Google` 안내를 기기의 스토어·동일 스토어 계정 안내로 수정했고 영어 번역에도 반영했다. 연간 자동 갱신·현지 가격·복원·해지·오프라인·로컬 데이터 손실 설명은 보존했다. iOS/Android × 한국어/영어의 실제 위젯 회귀 8개와 기존 구독 4개, 총 12개 테스트 및 정적 분석을 통과했다. 이 소스 변경이 기존 1001 바이너리를 변경하지는 않으므로 새 빌드 연결이 필요하다.
2. **스크린샷 전체 교체 검증**: Apple 한국어·영어 × iPhone 중형·대형·iPad의 42장을 다시 제작했다. 무료·가격·체험 광고를 없애고 Pro 구독 필요 표시는 유지한다. 개인정보 카드 원본 4장은 실제 Flutter 화면에서 다시 캡처했으며 픽셀을 덧칠하지 않았다. 가격·타 플랫폼 광고를 차단하는 정책 회귀 5개, 전체 PNG 56장·자산 4개 규격 검사, Apple 42개 원본·출력 SHA 확인과 ZIP 2개 각 22파일의 SHA 대조를 통과했다. Pro 심사용 화면 4개도 새 코드로 다시 렌더했고 한·영 캡처 테스트 2개가 통과했다. Android 관련 기존 37개 파일의 SHA는 그대로다. 실제 Apple 업로드·처리 완료 확인은 아직 남아 있다.
3. **지원 사이트**: `store/site/`의 한국어·영어 index/support/privacy/terms 8개 HTML을 현재 출시 대상인 App Store 지원에 맞게 교정했다. 다른 모바일 플랫폼·Google Play 취소/환불 링크·해당 플랫폼의 정확 알람 권한 안내를 제거하고, App Store 결제와 구매 시 사용한 동일 Apple 계정의 구매 복원으로 설명을 통일했다. 무료 기능·7일 비자동결제 체험·연간 갱신·로컬 삭제/복구 제한, 이메일 문의의 Gmail 처리와 GitHub Pages IP 보안 로그 안내는 보존했다. 위젯의 표시용 정보와 앱으로 이어지는 시작·미루기 동작의 Pro 권한도 명시했다. 마지막 수정일은 2026-10-16이며 기존 URL을 변경하지 않았다. 공개 게시·응답 검증은 별도 담당 작업으로 남긴다.
4. **실결제 검증**: 기존 기록상 실제 iPhone StoreKit 구매·복원·취소·갱신·만료·환불 검증은 완료로 확인되지 않았다. 메타데이터 수정은 그 검증을 대신하지 않으며 성공 증빙으로 표현하지 않는다.
5. **승인 보장 금지**: 이 검수는 이번 반려 원인과 관련한 공개 문안의 정합성을 점검한 결과다. Apple의 전체 정책 적합성이나 다음 심사 승인을 보장하지 않는다.
