# 스토어 제출 문안 초안

계정 정보·지원 이메일·개인정보 안내 URL을 확정하기 전에는 제출하지 않는다. 현재 구현과 실제 기기 검증 결과에 맞춰 제출 직전에 재검토한다.

## 앱 이름

한걸음

## 소개

미루던 일, 한 가지부터 시작해요.

일정을 저장하는 데서 끝나지 않고 지금 시작할 작은 행동을 정하는 할 일 앱입니다. 오늘과 이번 주의 일정을 캘린더에서 확인하고, 바로 시작하거나 잠시 미뤄 다시 알림을 받을 수 있습니다.

- 날짜·시간·우선순위·반복 일정
- 시작·진행 중·보류·완료 상태
- 10분·30분·1시간 미루기와 재알림
- 반복해서 미루면 작은 첫걸음으로 5분 시작
- 최근 30일의 완료와 미루기 기록
- 회원가입 없이 기기에 저장

처음 7일은 전체 기능을 체험할 수 있으며 체험만으로 결제되지 않습니다. 이후 캘린더·메모·완료는 무료, 알림·미루기·실행 보조·통계는 Pro 연간 구독으로 제공됩니다. 기본 캘린더와 메모는 인터넷 없이 사용할 수 있습니다. 구독 기능은 마지막 스토어 확인 후 최대 24시간 오프라인으로 사용할 수 있으며 이후 인터넷으로 재확인이 필요합니다. 알림을 받으려면 기기의 알림 권한이 필요합니다. 앱 삭제나 기기 변경 시 기록이 사라질 수 있습니다. 알림은 기기 설정과 예약 범위의 영향을 받습니다. 의료·진단 서비스를 제공하지 않습니다.

## 개인정보 안내 초안

한걸음은 사용자가 입력한 할 일 제목·메모·일정·진행 상태와 행동 기록을 기기의 로컬 데이터베이스에 저장합니다. 개발자의 서버로 전송하지 않습니다. 회원가입, 광고 SDK, 분석 SDK 및 클라우드 동기화를 포함하지 않습니다. 선택형 Pro 연간 구독은 Apple 또는 Google의 결제 시스템에서 처리하며 앱은 스토어가 제공하는 구매·구독 상태를 확인합니다. 개발자가 카드 정보를 직접 수집하지 않습니다. 최종 개인정보 표시와 데이터 보안 설문은 스토어 SDK의 실제 데이터 처리 범위에 맞춰 검토해야 합니다.

알림 권한은 사용자가 정한 일정과 재알림을 표시하는 데 사용합니다. 앱 데이터는 앱 삭제 시 제거될 수 있고, 별도 복구 서비스를 제공하지 않습니다. 앱 안에서 할 일을 삭제하면 해당 반복 시리즈와 기록이 삭제됩니다.

지원·개인정보 문의 연락처: **제출 전 개발자가 지정해야 함**.

이 문안은 스토어용 초안이며 공개 개인정보 안내 페이지로 게시된 상태가 아닙니다.

## 제출 전 입력

- 지원 이메일 및 지원 URL
- 개인정보 안내 페이지의 공개 URL
- 앱 카테고리, 국가·가격, 연령 등급
- 실제 앱 스크린샷과 아이콘
- Apple 앱 개인정보·Google 데이터 보안 설문: 최종 릴리스의 데이터 수집·전송 동작을 기준으로 답변
- Apple Developer Team 및 Google Play 앱 서명·테스트 요건
- 두 스토어에 맞춘 수동 공개 일정
