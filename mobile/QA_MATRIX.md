## 제품/보안 한계

- 첫 7일은 설치 단위 로컬 체험이며 앱 삭제/데이터 조작까지 막는 사용자당 1회 체험이 아니다.
- 앱 자체의 계정/서버가 없으므로 iOS와 Android 구매는 공유하지 않는다.
- 앱 미실행·통신 실패만으로 유료 권한을 끊지 않는다. 알려진 실제 만료일은 적용하며 Android처럼 만료일이 제공되지 않으면 다음 스토어 확인까지 유지한다. 오프라인 중 만료·환불 반영은 지연될 수 있다. 기존 24시간 캐시는 새 스토어 확인 전까지 기존 만료 경계를 유지한다.
- OS 권한·절전·집중 모드·예약 개수 제한은 별도 실기기 검수가 필요하다. 배너의 정확한 표시 시각과 OS 백그라운드 실행을 앱이 보장하지 않는다.
- `main.dart`가 배포 진입점이다. `preview.dart`의 샘플 구독/데이터를 배포 빌드에 사용하지 않는다.
