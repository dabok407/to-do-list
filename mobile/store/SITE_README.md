# 투두닉 / Todoniq 지원 사이트

한국어와 English로 읽을 수 있는 정적 안내 페이지다. **나만의 할 일, 투두닉 / Your tasks. Your way.**를 소개하고, 할 일·메모를 기기에 저장하며 개발자 서버로 보내지 않는 점을 첫 화면에 안내한다. 회원가입과 광고 추적 없이 일정을 관리할 수 있다. 이 사이트는 앱 데이터 저장이나 알림 처리를 위한 서버가 아니다.

공개 사이트는 [https://dabok407.github.io/to-do-list/](https://dabok407.github.io/to-do-list/)이며 고객 문의 이메일은 `dabok407@gmail.com`이다. 메일은 사용자가 메일 앱에서 직접 보내며, 페이지에는 문의 수집 폼·외부 JavaScript·분석 도구·외부 폰트가 없다.

각 페이지 상단의 한국어/English 링크는 같은 안내의 다른 언어로 이동한다. 별도 계정·쿠키·언어 저장 코드 없이 동작하며, 선택한 언어로 사이트 메뉴를 계속 이용할 수 있다. `style.css`는 공통 스타일이다.

GitHub Pages는 정적 호스팅만 담당한다. 앱 데이터와 별도로, 사이트 방문 IP 주소가 GitHub의 보안 정책에 따라 기록될 수 있으며 개인정보 페이지에 이 내용을 안내한다.

2026-10-10 새 **투두닉 / Todoniq** 브랜드의 [GitHub Pages 배포 38040488335](https://github.com/dabok407/to-do-list/actions/runs/38040488335), 소스 `2567bb4`가 성공했다. 8개 HTML의 HTTP 200과 각 언어의 새 브랜드를 확인했으며 실제 CUA 브라우저에서도 한국어·영어 지원 첫 화면을 검토했다. 기존 앱 설정·Pro 링크 연결과 링크 컴포넌트 테스트 5개도 통과했다. URL과 고객 문의 이메일은 유지한다.

언어에 따라 해당 지원·개인정보 안내를 열고 iOS의 이용약관은 Apple 표준 EULA를 연다. 구매·구독 확인의 스토어 통신, 사용자가 직접 보내는 이메일과 GitHub Pages 접속 정보는 앱의 로컬 기록과 구분하여 설명한다. 배포 기록, 콘솔 연결 현황과 남은 운영 검토는 사이트 폴더 밖의 [`SITE_REVIEW.md`](SITE_REVIEW.md)에서 관리한다. Apple 콘솔에는 아직 첫칸 이름과 기존 이미지가 저장되어 있으며 로그인 세션 만료로 새 브랜드 반영은 대기 중이다. 실제 구독 상품·서명 IPA·TestFlight·스토어 심사 제출은 아직 완료하지 않았다.
